# Guía de Contribución

Este documento define las reglas iniciales de colaboración para el proyecto EcuaRutas.

## Flujo de trabajo

El proyecto utilizará Git y GitHub siguiendo el modelo GitFlow.

Las ramas principales son:

- `main`: versiones estables.
- `develop`: integración del desarrollo.
- `feature/*`: desarrollo de nuevas funcionalidades.
- `release/*`: preparación de versiones.
- `hotfix/*`: correcciones urgentes.

## Reglas iniciales

- No desarrollar directamente sobre `main`.
- Crear nuevas funcionalidades desde `develop`.
- Realizar commits claros y relacionados con un cambio concreto.
- Integrar cambios mediante Pull Requests.
- Revisar los cambios de otros integrantes antes del merge.
